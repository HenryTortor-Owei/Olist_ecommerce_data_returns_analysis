# Olist E-commerce Returns Analysis

## Overview

An end-to-end data analytics project analyzing e-commerce orders to understand **returns, cancellations, delivery performance, payments, customers, and sellers**.

The project uses the Olist Brazilian E-commerce dataset.

## Tools

* **Python & Pandas** — Data cleaning and transformation
* **Jupyter Notebook** — Exploratory Data Analysis
* **MySQL** — Data analysis and SQL queries
* **Power BI** — Dashboard and visualization
* **Git & GitHub** — Version control

## Project Workflow

**Data Cleaning → EDA → SQL Analysis → Business Insights → Power BI Dashboard**

## Key Areas of Analysis

* Returns and cancellations
* Delivery performance
* Product and category performance
* Customer locations
* Seller performance
* Payment methods
* Order trends

## Dashboard

The Power BI dashboard presents the main findings from the analysis and allows users to explore the return and order patterns interactively.
